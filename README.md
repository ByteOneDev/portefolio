## Project Requirements Document (PRD) / Brief

**Project Title:** Ultimate Strategic Portfolio Landing Page (Vintage Terminal Style)
**Version:** 1.0
**Date:** October 26, 2023
**Author:** Product Manager (Based on Matthieu Perez's requests)

---

### 1. Introduction / Executive Summary

This project aims to consolidate the existing portfolio content for Matthieu Perez into a single, cohesive landing page.
The design will fully embrace and extend the established **"Vintage Terminal"** aesthetic, creating a unified narrative
that reflects Matthieu's expertise in Computer Science, Chess, and History. The goal is to provide a fluid and impactful
user experience, guiding visitors through Matthieu's profile, skills, and background on a single scrollable page.

**Project Goal:** To design and implement a comprehensive, single-page landing page for Matthieu Perez's professional
portfolio, leveraging the "Vintage Terminal" style to enhance brand identity and user flow.

**Context:** Matthieu Perez's portfolio currently features a "Brutalist Industrial" design with a strong emphasis on
code (terminal), strategy (chess), and historical context. The previous iteration involved applying a "Vintage Terminal"
style (green on black, monospace fonts) to the homepage. This project builds upon that by merging previously separate
content into one continuous page.

### 2. Target Audience

* Potential employers in tech, data science, or strategy roles.
* Collaborators and networking contacts.
* Academics or individuals interested in Computer Science, Chess, and History.

### 3. Key Features / Requirements

#### 3.1 Visual Design & Style

* **Overall Aesthetic:** "Vintage Terminal" and "Brutalist Industrial."
* **Color Palette:**
    * Primary Accent: Electric Green (`#00FF41`) for text, grid lines, radar chart, and icons.
    * Background: Obsidian Black (`#050505`) for a very dark, high-contrast effect.
* **Typography:**
    * Headers (main titles): Bold Serif font (for historical/archive nod).
    * Body Text: Courier-style monospace font (for all informational text, dates, CV content, reinforcing the
      terminal/typewriter feel).
* **Layout:** Strict brutalist grid layout throughout the entire page.

#### 3.2 Content Structure & Flow (Top to Bottom)

The landing page content must be integrated seamlessly and flow in the following order:

1. **Navigation Bar:**
    * Located at the top.
    * Content: Navigation links presented with chess notation (e.g., A1, B2).
2. **Hero Section:**
    * Features the main "About Me" text.
    * Includes a prominent professional tech logo/icon (e.g., CPU/Brain).
3. **Strategic Skills Radar Chart Section:**
    * Integrated directly into the brutalist grid.
    * Chart elements (lines, labels) rendered in electric green.
4. **Education Section:**
    * Details educational background and experiences.
    * Decorated with wireframe chess piece icons (e.g., Knight, King, Rook) as visual markers.
5. **Historical/Tech Quotes:**
    * Quotes from figures like Tesla or Napoleon to be interspersed between major sections.
    * Serve as visual and thematic dividers, reinforcing the history/tech link.
6. **Footer:**
    * Features the bold slogan: "EXPLAIN. BUILD. DECODE." (as styled by Anis Ayari).

#### 3.3 Branding & Identity

* **Core Message:** Reinforce the strong link between computer code (the terminal), strategic thinking (chess), and a
  modern "archive folder" structure.
* **Personality:** Technical, strategic, analytical, historically aware, and modern.

### 4. Scope (In / Out)

**In Scope:**

* Merging all specified content into a single, scrollable landing page.
* Implementing the "Vintage Terminal" visual style (colors, typography, grid).
* Ensuring content sections follow the defined order and incorporate specific visual elements (icons, charts, quotes).
* Responsive design for various screen sizes to maintain the brutalist grid aesthetic.

**Out of Scope (for initial release):**

* Any interactive animations beyond basic hover states.
* Additional page sections not explicitly listed (e.g., project gallery, blog).
* Alternative color schemes (e.g., 'Monochrome White').
* Advanced background effects (e.g., 'Matrix' scrolling characters).

### 5. Future Considerations / Ideas (Backlog)

* Add an animation of a blinking cursor on selected titles (e.g., in the Hero section).
* Propose a version with 'Monochrome White' text on a Black background (Style: 'Paper Terminal').
* Create a dedicated 'Journal de Bord' (Logbook) section using the typewritten text style.
* Implement a 'Scroll to Top' button with a pawn icon.
* Develop a 'Galerie de Projets' (Project Gallery) section with 'Blueprint' style screenshots.
* Explore a 'Matrix' version with scrolling characters in the background for an alternative theme.

### 6. Success Metrics

* **Completion:** All specified content sections are integrated into a single landing page.
* **Adherence to Design:** The "Vintage Terminal" style (colors, typography, grid) is consistently applied throughout
  the page.
* **Content Flow:** The sections are presented in the correct order, creating a logical and engaging narrative.
* **Visual Coherence:** The page successfully conveys the desired brand identity (code, chess, history).
* **Functionality:** The landing page is fully functional and responsive across devices.
